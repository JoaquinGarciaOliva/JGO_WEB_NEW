Ejemplos Prácticos: Números Enteros ($\mathbb{Z}$)

Ejemplos Resueltos sobre la Introducción a los Números Enteros

A continuación se presentan cuatro bloques conceptuales resueltos: identificación de signo y número, construcción del número entero, análisis de afirmaciones teóricas (Verdadero/Falso) y la transformación de expresiones del lenguaje ordinario a números enteros.

Bloque 1: Identificación del Signo y el Número
Ejemplo 1:
$$\text{Dada la lista de números: } -4, \quad +9, \quad 6, \quad -12, \quad 0$$ $$\begin{aligned} -4 &\longrightarrow \text{Signo: negativo (-)}, \quad \text{Número: } 4 \\ +9 &\longrightarrow \text{Signo: positivo (+)}, \quad \text{Número: } 9 \\ 6 &\longrightarrow \text{Signo: positivo (+, omitido)}, \quad \text{Número: } 6 \\ -12 &\longrightarrow \text{Signo: negativo (-)}, \quad \text{Número: } 12 \\ 0 &\longrightarrow \text{Signo: no tiene (neutro)}, \quad \text{Número: } 0 \end{aligned}$$
    Regla aplicada: Todo número entero está formado por un signo ($+$ o $-$) y un número. Si un número no lleva signo escrito delante (como el $6$), se entiende que es positivo ($+6$). El cero es el único número entero neutro: no es positivo ni negativo.
Bloque 2: Formación del Número Entero a partir de Signo y Número
Ejemplo 2:
$$\text{Escribir el número entero correspondiente a cada descripción:}$$ $$\begin{aligned} \text{Signo negativo } (-) \text{ y número } 8 &\longrightarrow -8 \\ \text{Signo positivo } (+) \text{ y número } 15 &\longrightarrow +15 \quad (\text{o simplemente } 15) \\ \text{Signo negativo } (-) \text{ y número } 3 &\longrightarrow -3 \\ \text{Sin signo y número } 0 &\longrightarrow 0 \\ \text{Signo positivo } (+) \text{ y número } 1 &\longrightarrow +1 \quad (\text{o simplemente } 1) \end{aligned}$$
    Regla aplicada: Para escribir un entero se coloca primero el signo correspondiente seguido inmediatamente de su número. Los enteros positivos se pueden escribir con o sin el signo $+$.
Bloque 3: Análisis de Frases Teóricas (Verdadero o Falso)
Ejemplo 3:
$$\text{Indicar si las siguientes afirmaciones son Verdaderas (V) o Falsas (F):}$$
    a) Todo número natural ($\mathbb{N}$) es también un número entero ($\mathbb{Z}$).
    Respuesta: Verdadero (V).
    Explicación: El conjunto de los números naturales $\mathbb{N} = \{0, 1, 2, 3, \dots\}$ está contenido dentro del conjunto de los enteros $\mathbb{Z}$, ya que los naturales corresponden a los enteros positivos y el cero ($\mathbb{N} \subset \mathbb{Z}$).

    b) El número $-5$ pertenece al conjunto de los números naturales ($\mathbb{N}$).
    Respuesta: Falso (F).
    Explicación: Los números naturales solo incluyen valores no negativos ($0$ y positivos). Los números con signo negativo son enteros ($\mathbb{Z}$), pero no naturales.

    c) El número cero ($0$) tiene signo positivo.
    Respuesta: Falso (F).
    Explicación: El cero es un elemento neutro; es el único número entero que no es ni positivo ni negativo.

    d) El conjunto $\mathbb{Z}$ está formado por los enteros positivos, los enteros negativos y el cero.
    Respuesta: Verdadero (V).
    Explicación: Esta es la definición exacta del conjunto de los números enteros: $\mathbb{Z} = \{\dots, -3, -2, -1, 0, +1, +2, +3, \dots\}$.
Bloque 4: Transformación del Lenguaje Ordinario a Números Enteros
Ejemplo 4:
$$\text{Expresa mediante un número entero cada una de las siguientes situaciones cotidianas:}$$ $$\begin{aligned} \text{a) Debo } 30 \text{ euros} &\longrightarrow -30 \\ \text{b) Tengo } 50 \text{ euros en la cartera} &\longrightarrow +50 \quad (\text{o } 50) \\ \text{c) El helicóptero vuela a } 200\text{ m sobre el nivel del mar} &\longrightarrow +200 \\ \text{d) Un submarino navega a } 45\text{ m de profundidad} &\longrightarrow -45 \\ \text{e) La temperatura es de } 3^\circ\text{C bajo cero} &\longrightarrow -3 \\ \text{f) Un ascensor sube a la planta } 4 &\longrightarrow +4 \\ \text{g) El aparcamiento está en el segundo sótano} &\longrightarrow -2 \end{aligned}$$
    Regla aplicada:
      Se asigna el signo negativo ($-$) a deudas, profundidades, temperaturas bajo cero, niveles bajo tierra o pérdidas. Se asigna el signo positivo ($+$) a dinero que se posee, alturas sobre el nivel del mar, temperaturas sobre cero, pisos superiores o ganancias.
