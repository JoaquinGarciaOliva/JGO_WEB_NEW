Ejemplos Prácticos: Números Enteros ($\mathbb{Z}$) - ORDEN

Ejemplo 1: Ordenar Números Enteros de Menor a Mayor
Enunciado:

Ordena de menor a mayor los siguientes números enteros utilizando el símbolo $<$: $$+4, \quad -5, \quad 0, \quad -2, \quad +1, \quad -6$$

Resolución:
$$\text{1. Identificamos los números negativos: } -6, -5, -2$$ $$\text{2. Comparamos los negativos (el más alejado del cero es el menor): } -6 < -5 < -2$$ $$\text{3. El cero se ubica entre los negativos y los positivos: } -2 < 0$$ $$\text{4. Comparamos los positivos: } 0 < +1 < +4$$

Resultado final:

$$-6 < -5 < -2 < 0 < +1 < +4$$
    Regla aplicada: Cuanto más a la izquierda (o más abajo en el ascensor) esté un número, menor es su valor. Recuerda que entre dos números negativos, es menor el que tiene mayor valor absoluto (está más lejos del $0$).
Ejemplo 2: Ordenar Números Enteros de Mayor a Menor
Enunciado:

Ordena de mayor a menor los siguientes números enteros utilizando el símbolo $>$: $$-3, \quad +5, \quad -1, \quad +2, \quad -7, \quad 0$$

Resolución:
$$\text{1. Identificamos los números positivos y el mayor de ellos: } +5 > +2$$ $$\text{2. Los positivos son mayores que el cero: } +2 > 0$$ $$\text{3. El cero es mayor que cualquier negativo: } 0 > -1$$ $$\text{4. Ordenamos los negativos de mayor a menor (más cerca del cero a más lejos): } -1 > -3 > -7$$

Resultado final:

$$+5 > +2 > 0 > -1 > -3 > -7$$
    Regla aplicada: Al ordenar de mayor a menor comenzamos por el entero positivo situado más a la derecha y avanzamos hacia la izquierda en la recta real.
Ejemplo 3: Representación Gráfica de Enteros en la Recta Real
Enunciado:

Representa en una recta real los siguientes números enteros: $$-4, \quad -1, \quad 0, \quad +3, \quad +5$$

Gráfico explicativo:
Explicación:
  • Trazamos la recta dividida en marcas equidistantes (a la misma distancia unas de otras).
  • Situamos el origen $0$ como punto de referencia.
  • Contamos a la izquierda para los negativos: $-1$ (1 unidad a la izquierda) y $-4$ (4 unidades a la izquierda).
  • Contamos a la derecha para los positivos: $+3$ (3 unidades a la derecha) y $+5$ (5 unidades a la derecha).
Ejemplo 4: Identificación de Letras en la Recta Real
Enunciado:

Dada la siguiente recta real donde se indica el número de referencia $0$, averigua a qué número entero corresponde cada una de las letras ($A$, $B$, $C$ y $D$):

Gráfico del problema:
Resolución paso a paso:
$$\begin{aligned} \text{Tomando como origen el número } 0: & \\ \text{Para } B: &\text{ Contamos 2 divisiones hacia la izquierda } \longrightarrow B = -2 \\ \text{Para } A: &\text{ Contamos 5 divisiones hacia la izquierda } \longrightarrow A = -5 \\ \text{Para } C: &\text{ Contamos 2 divisiones hacia la derecha } \longrightarrow C = +2 \text{ (o } 2\text{)} \\ \text{Para } D: &\text{ Contamos 4 divisiones hacia la derecha } \longrightarrow D = +4 \text{ (o } 4\text{)} \end{aligned}$$

Resultado final:

$$A = -5, \quad B = -2, \quad C = +2, \quad D = +4$$
Ejemplo 5: Comparación Visual de Números Negativos
Enunciado:

Representa en la recta real los enteros $-2$ y $-6$. Justifica gráficamente cuál de los dos es mayor.

Gráfico explicativo:
Resolución y Justificación:
$$-2 > -6$$
  • Justificación gráfica: En la recta real, los números aumentan su valor a medida que avanzamos hacia la derecha. Como el punto $-2$ se encuentra más a la derecha que el punto $-6$, concluimos que $-2$ es mayor que $-6$.
  • Justificación intuitiva (ascensor): Estar en el sótano $-2$ es estar a mayor altura que estar en el sótano $-6$.
